Instalação e protocolo

Para instalar: abra o endereço publicado deste app no Chrome (Android) ou Safari (iPhone), escolha “Adicionar à tela inicial” / “Instalar aplicativo”.

O banco é armazenado localmente neste aparelho e navegador. Faça backups regulares; limpar os dados do navegador pode apagar os registros.

Equações implementadas

Velocidade média = distância ÷ 360 s.

Estágios equivalentes = distância ÷ 20 m.

Saltos estimados = −1,749 + (0,153 × distância).

Mudanças de direção estimadas = −0,893 + (0,251 × distância).

As duas regressões só são exibidas para distância superior a 500 m, conforme a regra de cautela adotada nesta ferramenta. Confirme a faixa de validade e o protocolo no artigo original antes de interpretar os resultados.

Privacidade

Os dados ficam no armazenamento local do navegador. Não há envio automático para servidor. Evite inserir dados sensíveis desnecessários.
